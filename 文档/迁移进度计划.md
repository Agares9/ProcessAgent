# ProcessAgent 项目迁移进度计划

## 1. 项目定位

目标目录：`D:\workfile\ProcessAgent`

ProcessAgent 是面向大型制造企业管理者和专业人员的场景决策 Agent 平台。系统接收集团、工厂、工艺、能源、质量、成本和 ESG 等复杂问题，通过意图识别、企业上下文查询、任务规划、多专业 Agent 分析、确定性计算、证据校验和管理层汇总，形成可追溯、可计算、可执行的解决方案。

基础技术来源：

| 来源项目 | 路径 | 主要复用范围 |
|---|---|---|
| 文枢 | `D:\BaiduNetdiskDownload\wenshu-project` | 主工程底座、文档治理、权限、版本、混合检索、Verifier、任务队列、测试与部署 |
| 差旅项目6 | `D:\BaiduNetdiskDownload\简历项目6：差旅出行助手\项目6` | 多意图识别、Plan-and-Execute、优先级并行、Lazy Registry、Skill动态注册 |
| MediX医疗助手 | `D:\workfile\medix-agent-swarm` | Skill/function calling、SharedContext、约束、Milvus、进度事件、模型预热和异步问答经验 |

总体原则：

> 以文枢代码为主底座；吸收项目6的意图识别与优先级调度；选择性迁移医疗助手的Skills、约束、Milvus和运行经验；制造业领域模型、计算与专业Agent重新实现。

## 3. 目标架构

```text
React/Next.js 场景端与管理后台
        ↓
FastAPI + Auth + Tenant RBAC + Audit
        ↓
ManufacturingIntentAgent
        ↓
EnterpriseContext + DataCompletenessCheck
        ↓
LeadAgent / Orchestrator / Plan-and-Execute
        ↓
专业 Agents 并行分析
        ↓
Skills + RAG + 确定性计算服务
        ↓
VerifierAgent
        ↓
ExecutiveSynthesisAgent
        ↓
管理层方案、工厂任务和实施路线图
```

数据层：

```text
对象存储/文件系统：原始 PDF、报告、SOP、图纸
MongoDB：文档、Chunk、版本、许可、审核和关系
PostgreSQL：集团、工厂、设备、工艺、能源、项目和计算事实
Milvus：制造知识 Chunk 与向量索引
BM25/OpenSearch：标准号、型号、术语和全文关键词检索
Redis：任务、缓存和短期会话
时序库（后续）：设备、能源、产量和质量时序数据
```
